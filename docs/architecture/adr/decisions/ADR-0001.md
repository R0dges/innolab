# ADR-0001 — Réunir l’interface et l’API dans une application Next.js

| Champ | Valeur |
|---|---|
| Domaine | Socle et architecture |
| Statut documentaire | Vérifié techniquement |
| Statut d’arbitrage | Non arbitré |
| Baseline vérifiée | `develop@2c0b7f82` |

## N0 — En clair

Juryza utilise une seule application Next.js pour le site, les écrans connectés et l’API. Les packages partagés restent dans le même monorepo.

**Impact métier :** une seule application à construire et déployer. Une panne ou une évolution du socle peut toutefois toucher simultanément l’interface et l’API.

**Proposition de l’audit :** conserver ce choix, en le décrivant comme **un déployable Next.js dans un monorepo**, et non comme un monolithe sans packages.

## N1 — Ce que montre l’historique

- **Observé — origine :** [`e8b34068`](https://github.com/R0dges/innolab/commit/e8b340680fc28114d6699d9a68e72e11c2a2e02c) crée `apps/juryza`, Next.js 16 et la route Better Auth. C’est encore un scaffold.
- **Observé — première version fonctionnelle :** [`f14bec2b`](https://github.com/R0dges/innolab/commit/f14bec2b8103cba4cb50731459a4d9839578e96d) ajoute les routes métier, la base et le conteneur applicatif.
- **Observé — architecture actuelle :** [`82b1a7be`](https://github.com/R0dges/innolab/commit/82b1a7be32fe31702fdd50bb39d1e35b4eb1309e) réorganise pages, routes et services tout en gardant un seul déployable.
- **Déclaré :** `ARCHITECTURE.md` décrit une application Next.js unique pour l’UI et l’API.
- **Justification historique :** non trouvée. Le choix était déjà présent dans create-notils.

## Compromis

- Positif : déploiement simple, types et code partagés, pas de backend séparé.
- Négatif : couplage du cycle de livraison et discipline nécessaire entre code client et serveur.
- Alternatives non attestées : frontend et backend séparés ; services indépendants.

## Contrôle qui pourrait réfuter le choix

Mesurer si les besoins de montée en charge, de sécurité ou de livraison imposent réellement des cycles indépendants pour l’API et l’interface. Ce contrôle n’a pas été exécuté pendant l’audit.
