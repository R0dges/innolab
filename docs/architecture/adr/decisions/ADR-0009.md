# ADR-0009 — Fournir un environnement local avec Docker Compose

| Champ | Valeur |
|---|---|
| Domaine | Exploitation |
| Statut documentaire | Vérifié techniquement |
| Statut d’arbitrage | Accepté le 2026-10-26 |
| Baseline vérifiée | `develop@2c0b7f82` |

## N0 — En clair

`docker compose up` lance PostgreSQL et le portail Juryza, applique les migrations et charge les données de démonstration.

**Impact métier :** une personne peut lancer une instance de démonstration complète sans service cloud obligatoire. Cette configuration locale ne doit pas être confondue avec la sécurité d’une production.

**Décision :** conserver Docker Compose comme référence pour lancer Juryza localement, exécuter les tests d’acceptation et fournir un serveur de démonstration. Les données de démonstration ne doivent jamais être chargées en production. Les secrets, paramètres et procédures de production restent séparés et font l’objet d’une documentation dédiée.

## N1 — Ce que montre l’historique

- **Justification attestée :** `spec.md` exige explicitement un portail seedé lancé par `docker compose up`, sans base hébergée ni API externe.
- **Observé — première implémentation :** [`f14bec2b`](https://github.com/R0dges/innolab/commit/f14bec2b8103cba4cb50731459a4d9839578e96d) ajoute Compose, PostgreSQL 18, le Dockerfile et l’entrypoint.
- **Observé — migrations :** [`86c5a13b`](https://github.com/R0dges/innolab/commit/86c5a13bfe3b6c618f6d299e74d9457a67316107) remplace le simple `db:push` au démarrage par le migrateur versionné.
- **Observé — production :** [`d8be424e`](https://github.com/R0dges/innolab/commit/d8be424edbb42fe822146131267ce1284b5cd7ca) ajoute une infrastructure AWS/EC2. Compose n’est donc plus l’unique cible d’exploitation.
- **État publié actuel :** la configuration locale est toujours présente à `2c0b7f82`.

## Compromis et risque principal

Le démarrage est reproductible, mais le secret de démonstration, les ports et le seed ne constituent pas une politique de production. « Offline » décrit le runtime ; construire les images peut encore demander le réseau.

## Contrôle qui pourrait réfuter le choix

Construire et lancer depuis une machine propre, couper le réseau au runtime, redémarrer, migrer une ancienne base et restaurer une sauvegarde. Ces contrôles n’ont pas été exécutés pendant l’audit.

## Décision humaine

- Conclusion : **conserver Docker Compose pour le développement, les tests et la démonstration, sans en faire automatiquement la procédure de production**
- Décideur : **responsable produit Innolab**
- Date : **2026-10-26**
- Motif : **faciliter le lancement reproductible de Juryza tout en empêchant le mélange des données, secrets et réglages de démonstration avec la production**
- Condition de mise en production : **documenter et tester séparément le déploiement, les secrets, les migrations et la restauration**
